> A curated, continuously updated survey of the **embodied harness** stack: everything around a foundation model that turns it into an agent acting in the physical world. A daily radar agent keeps it current.

Coding agents showed that the model is only half the system. Claude Code, Codex and their peers succeed or fail on their **harness**: the loop, the tools, context management, permissions, and tests used as exit codes. Robots are going through the same split. An **embodied harness** wraps an LLM, VLM, VLA or world model with:

- an **agent loop** that plans, calls tools, observes and replans;
- robot capabilities exposed as **tools**: skills, VLA policies, motion primitives, generated code;
- **world state as context**: scene graphs, maps, object and episodic memory;
- **exit codes**: success detection, failure diagnosis and recovery;
- a **safety envelope**: guardrails, permissions, human-in-the-loop;
- the **sim / eval / data flywheel** used to build and test all of the above.

This list covers every layer of that stack, not just the models. [SURVEY.md](SURVEY.md) has the taxonomy, a comparison of representative harnesses, and open problems.

## Embodied Harnesses

> Systems where an LLM/VLM-driven agent loop orchestrates robot capabilities (skills, VLAs, motion primitives, generated code) and closes the loop on feedback.  
> Layer: L4 · 140 entries · **[full list →](categories/harness.md)**

- ⚪ [**World Action Agent (WAA)**](https://arxiv.org/abs/2609.29964 "World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal") · 2026-09 · HKUST (Guangzhou); CUHK; Knowin AI — Multi-agent harness where VLMs pilot robots inside a visual action workspace: auto-selected contact views, action rehearsal that previews and edits each action before execution, and in-view correction; skills evolve from expert videos and human teaching. _Note: Work in progress per arXiv comment; first-party 75.6% average on LIBERO-Pro._
- ⚪ [**What Stops Recursive Self-Improvement in Robotics?**](https://arxiv.org/abs/2609.31760 "What Stops Recursive Self-Improvement in Robotics? Lessons from 123 Rounds of Agentic Skill Discovery") · 2026-09 · National University of Singapore — Report on an agent that watches a robot fail, writes skills or installs models, tests in simulation and repeats for 123 rounds; gains did not compound, with bottlenecks in relational perception, skill chains that stall early, and the harness's evaluator and memory. _Note: Single-author technical report; a negative-results case study._
- 🟢 [**Show-Harness**](https://arxiv.org/abs/2609.10522 "Show-Harness: Just a VLM Agent Can Play Robots") · 2026-09 · Show Lab, National University of Singapore — Embodied harness where a VLM picks discrete semantic action units that embodiment-specific interpreters deterministically ground into robot motion, enabling zero-shot control by frontier VLMs and cheap fine-tuning of small VLMs; GUMI reuses the interface for GUI demo collection. [code](https://github.com/showlab/Show-Harness) · [project](https://showlab.github.io/Show-Harness/) · [weights](https://huggingface.co/showlab/Show-Harness-VLMs) · [data](https://huggingface.co/datasets/showlab/Show-Harness-Data)
- ⚪ [**SEES**](https://arxiv.org/abs/2609.32698 "SEES: A Self-Evolving Embodied System via Failure-Guided VLA Policy Adaptation") · 2026-09 — Routes atomic sub-tasks of long-horizon jobs to families of VLA skill adapters, monitors which atomic skills fail most, then builds targeted RL tasks in simulation (restored states, LLM-written success criteria) to improve them without new expert demonstrations.
- ⚪ [**SafeHarness**](https://arxiv.org/abs/2609.20822 "Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation") · 2026-09 · USC; UCF; UCSB — Shows coding-agent controllers usually touch obstacles they were told to avoid, then adds obstacle-aware route planning (bounding boxes, candidate waypoint routes, verify and replan before executing) and obstacle-aware contact selection. _Note: First-party SafeLIBERO simulation results using GPT-6 over a frozen pi0.5 with Harness VLA skills (71.9% success, 87.5% collision avoidance). Could also go under safety._
- ⚪ [**RoboFoundry**](https://arxiv.org/abs/2609.32862 "RoboFoundry: System-as-Policy Evolution for Self-Learning Embodied Agents") · 2026-09 · Nanyang Technological University; Beihang University; NUS et al. — Treats the agent's supporting system as the policy to evolve: it diagnoses capability gaps, turns execution traces into validated updates to a context/file-system memory and a hierarchical skill system with failure-conditioned recovery, and transfers across robots. _Note: Code repository lists evaluation code as TODO._ [project](https://jingsongliang.com/robofoundry)
- 🟢 [**RoboDawn**](https://arxiv.org/abs/2609.22966 "Transferring the Intelligence of VLMs to Robotic Control") · 2026-09 · Tsinghua University; Tencent Hunyuan — Exposes robot control to a frozen agentic VLM through a compact set of discrete translation, rotation and gripper commands in a closed observe-reason-act loop, plus in-context learning from a few demonstrations; evaluated on RoboTwin 2.0, RoboDojo and a real Franka. [code](https://github.com/Hugo-AGI/RoboDawn) · [project](https://robodawn.top/)
- ⚪ [**Robo-Harness K1**](https://arxiv.org/abs/2609.29389 "Robo-Harness K1: Harnessing Robot-Use Agents via Perception Augmentation") · 2026-09 — Robot-use agent framework that exposes perception as tools (calibrated depth, persistent visual anchors, spatial measurements, grasp hypotheses) so a VLM picks generic motions from returned 3D evidence; its tool-call traces also train a small student VLM.
- ⚪ [**RegenHarness**](https://arxiv.org/abs/2609.27612 "RegenHarness: A Robot Agent Harness with Evidence-Gated Recursive Self-Improvement") · 2026-09 · AI Lab, Country Garden Services; HUST; Omni AI — Harness coupling a model loop for proposals with an agent loop for dispatch, verification, commit and bounded recovery, with role-isolated contexts and versioned memory; an evidence-gated self-improvement protocol revises the harness config with regression checks and rollback. _Note: Demonstrated on a real quadruped for voice-triggered warehouse inspection._
- ⚪ [**Recursive Harness Distillation**](https://arxiv.org/abs/2609.33378 "Recursive Harness Distillation across Agents for Robot Manipulation") · 2026-09 · Seoul National University; KAIST — A strong agent distills its experience intervening on a VLA into a playbook for a lighter agent, then recursively refines the playbook from the light agent's execution feedback, so intervention knowledge is reused without updating model weights. _Note: First-party: real-world success 37.3% to 64.0%; SimplerEnv Bridge with a GR00T policy._

## World State, Memory & Spatial Context

> Scene graphs, semantic maps, spatial and episodic memory; the harness's context window onto the world.  
> Layer: L3 · 51 entries · **[full list →](categories/memory.md)**

- ⚪ [**Workspace Models**](https://arxiv.org/abs/2609.20820 "Workspace Models: Lightweight Robotic Memory via Saliency-Driven Supervision") · 2026-09 · MIT, CMU — Moves VLM calls to training time: a VLM labels task-salient current and past information, which is distilled into a lightweight latent 'workspace token' that policies use at deployment to solve memory-intensive tasks without in-the-loop VLM reasoning. _Note: CoRL 2026._
- ⚪ [**ME-Brain-1.0**](https://arxiv.org/abs/2609.24271 "ME-Brain-1.0: Memory, Cognition and Action for Evolving Embodied Intelligence") · 2026-09 · MachEmbodied — Self-evolving embodied system built as a loop of execution, experience acquisition and evolution: an evolvable hierarchical memory of multimodal trajectories, a cognitive core that turns experience into skills, and an event-driven action model. _Note: Repository is a project page (report and videos); the MachEmbodied GitHub org also hosts Li Auto's ME-VLM._ [project](https://github.com/MachEmbodied/ME-Brain-1.0)
