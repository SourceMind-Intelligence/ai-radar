## Signals

- **Coding agents now fill in missing capabilities, not just call existing ones.**
  - ELEVATE: when a quadrupedal manipulator's task program keeps failing for lack of a physical skill, a coding agent formulates and refines an RL problem, trains the missing whole-body controller, and adds it to the skill library. The acquired skills transferred to a real robot (18/20 and 16/20 on two tasks, first-party).
  - METATRON (NVIDIA): a frozen, promptable humanoid base policy whose skills are ordinary code that coding agents refine without retraining the policy.
  - Gym-Anything for Robotics: coding agents write the simulations themselves, checked by an adversarial audit loop. On the resulting RoboWorld test tasks, frontier models average 0.06 reward (first-party).
- **Long plans get explicit structure to check against.**
  - LOGIV compiles a plan into a task graph of condition-support and ordering edges, checks it physically during execution, and repairs only what a disturbance invalidated. It runs on top of existing VLA or world-action policies and reports +10–15 points (first-party).
  - ProLoop marks each subgoal as ongoing, deviated or completed from learned state relations.
  - ReSTEP releases real-robot episodes with frame-level error and recovery labels for training progress monitors.
- **The harness is becoming the unit of a navigation agent.** EvoLife (Ask to Evolve) combines a hybrid action space, asking for help (1.87 interactions per episode on average) and persistent spatial memory in one navigation harness evaluated on eight benchmarks.
- **Two more surveys on self-improvement and harnesses.** One covers recursive self-improvement in physical AI (mechanisms, evidence, evaluation); the other covers harnesses around video generation and world models.
