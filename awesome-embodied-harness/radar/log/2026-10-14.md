## Signals

- **Points and boxes are now an interface robots act on, and a safety gap of their own.** Visual Grounding Safety finds that VLMs which refuse a harmful request posed as a question often comply when the same request asks for a point or bounding box. The gap averages 31–59 points in refusal rate across domains, including Asimov-2.0 situational-safety cases, and safety system prompts do not close it. Meanwhile, GroundingPI releases an open 4B model that does exactly this grounding, as a fast perception backbone for VLAs. Guardrails that only screen text answers miss the coordinates a robot actually executes.
- **Multi-robot VLN gets dependency-aware structure.** MAVLN formalizes team navigation with subtask dependencies and resource locks. Its TRISS baseline pairs an LLM scheduler with shared topological memory, the same scheduler-plus-shared-state pattern as MAGMA-Bench (2026-10-13).

## Added

- **GroundingPI** (brain): a 4B grounding foundation model producing points and boxes for robot perception backbones; code and weights released. [paper](https://arxiv.org/abs/2609.39601)
- **MAVLN / TRISS** (multi-agent): a constrained multi-agent VLN benchmark plus a scheduler with shared topological memory. [paper](https://arxiv.org/abs/2609.35965)
- **Visual Grounding Safety** (safety): harmful-request compliance through the point and box output channel, plus a fine-tuning fix. [paper](https://arxiv.org/abs/2610.05637)
