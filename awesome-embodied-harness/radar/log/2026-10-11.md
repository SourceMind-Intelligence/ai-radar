## Signals

- **Simulation-only VLA training now reaches real homes.** SimVLA trains a mobile-manipulation VLA entirely on synthetic data: composed-skill actions, privileged-state VQA and simulated deployment rollouts. It transfers zero-shot to real homes and, by the authors' account, beats policies trained on 50 real in-domain demonstrations (first-party). It fits the week's broader pattern (Skill2Real, RoboBridge, Agentic RSR, SpatialHarness) of the simulator becoming part of the deployed system rather than only a data source.
- **Chained tasks need policies that start from wherever the last task ended.** Attacca trains goal-conditioned policies on full search-to-interact trajectories, so a task can begin from wherever the previous one left the agent. This complements Friday's skill-seam finding that displaced scene state, not the robot's pose, is what breaks skill chains.

## Added

- **SimVLA** (policy): a simulation-only VLA for zero-shot sim-to-real mobile manipulation; code and data released. [paper](https://arxiv.org/abs/2610.11248)
