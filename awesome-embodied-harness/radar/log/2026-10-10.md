# Radar · 2026-10-10

## Signals

- **The harness is becoming a runtime.** NavGPT-3 (open code and 8B weights) runs reasoning, acting and monitoring as threads, each with its own context, tools and permissions. An OS-like scheduler decides which thread drives the robot and can interrupt it when the world changes. SuperNav (open code) gives a pretrained multimodal LLM navigation tools instead of fine-tuning it. SpatialHarness keeps a simulated twin synchronized with real execution and renders extra virtual views, so a frozen GPT-6 Astra can see the spatial relations its cameras miss.
- **At the opposite pole: code with no model in the loop.** Embodied Turing Machines (COAP) argues that if code can measure robot, environment and task state accurately, every runtime decision can be code, shared across tasks, with no VLM or VLA at run time. RoboAware sits in between: a coding agent orchestrates skills, and a small learned coordinator picks which policy family to trust in each state.
- **Long-horizon failures are being traced to skill handoffs.** The skill-seam study finds that chained-skill failures come mostly from scene state left behind by earlier skills, and fixes them with detect, restore and resume. ManiUnit builds a 1,260-instance skill-level benchmark to diagnose the same handoff problem. RESETTLE triggers recovery when two independently sampled action proposals keep disagreeing.

## Added

- **NavGPT-3** (harness): an OS-like hierarchical navigation runtime with thread scheduling over an open NavGPT VLA; code and weights released. [paper](https://arxiv.org/abs/2610.10787)
- **SuperNav** (harness): a pretrained multimodal LLM plus a navigation tool harness for any task in any scene; code released. [paper](https://arxiv.org/abs/2610.12126)
- **SpatialHarness** (harness): test-time virtual views from a synchronized simulated scene for frozen multimodal policies. [paper](https://arxiv.org/abs/2610.12457)
- **Embodied Turing Machines (COAP)** (harness): code-only policies over explicitly tracked state, with a shared library and no model at run time. [paper](https://arxiv.org/abs/2610.12369)
- **RoboAware** (harness): a learned responsibility coordinator for coding-agent skill orchestration, trained on counterfactual branches. [paper](https://arxiv.org/abs/2610.11480)
- **Skill-SLM** (harness): grammar-constrained skill composition for onboard small language models. [paper](https://arxiv.org/abs/2610.10812)
- **iAm.md** (interface): a Markdown self-description standard so agents check robot capabilities before generating behaviour. [paper](https://arxiv.org/abs/2610.10962)
- **RESETTLE** (verification): disagreement-triggered retrieval and corrective control around frozen policies. [paper](https://arxiv.org/abs/2610.12185)
- **Skill-seam observation-space shift** (verification): diagnosis and detect–restore–resume recovery at skill handoffs. [paper](https://arxiv.org/abs/2610.10810)
- **ManiUnit** (benchmark): a skill-level dataset and benchmark built from BEHAVIOR-1K. [paper](https://arxiv.org/abs/2610.12089)
- **DreamTrue** (world-model): an action-faithful, cross-embodiment world model with counterfactual post-training (CASIA and Amap, Alibaba); code and checkpoints released. [paper](https://arxiv.org/abs/2610.12468)
- **USDCraft** (sim): an LLM writes executable programs for simulation-ready articulated assets from partial meshes. [paper](https://arxiv.org/abs/2610.11322)
