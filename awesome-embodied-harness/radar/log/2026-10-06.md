# Radar · 2026-10-06

## Signals

- **Sim-to-real is moving from retraining policies to transferring verified skills.**
  - Skill2Real: frontier-model agents learn executable skills against a shared robot API, with a Proposer–Verifier–Governor loop that checks each update against privileged simulator evidence. The resulting skill memories run on a real robot without fine-tuning.
  - RoboBridge: represents tasks as procedures with built-in outcome verification and revises them from feedback in both simulation and reality.
  - MobiAgent (CoRL 2026): pairs a VLM planning-and-reflection loop with an outer loop for lifelong self-improvement in mobile manipulation.

  With last week's RPG, SimEX and Recova, "practice in simulation, verify, then deploy the skill library" is now the dominant harness recipe.
- **The frontier/local split is getting explicit plumbing.** The frontier-to-local bridge paper uses the slow frontier model to generate demonstrations, including corrective segments, and pairs its instructions with a fast local policy trained to follow them. This is the same split as dual-system VLAs, but implemented in the harness rather than in the weights.
- **Safety evaluation keeps getting more physical.** ManiPhysicsBench checks whether grasps would deform or break objects, not just whether tasks succeed. Detect and Suppress defends VLAs against adversarial patches by switching off one sparse-autoencoder feature only when a probe detects an attack.

## Added

- **MobiAgent** (harness): dual-loop VLM planning, atomic-skill experts and lifelong self-improvement for mobile manipulation; checkpoint on Hugging Face. [paper](https://arxiv.org/abs/2610.03476)
- **Skill2Real** (harness): agentic skill learning through a Proposer–Verifier–Governor loop, with zero-shot sim-to-real skill memories. [paper](https://arxiv.org/abs/2610.02788)
- **RoboBridge** (harness): sim-to-real as continued adaptation of verifiable, executable procedures. [paper](https://arxiv.org/abs/2610.02717)
- **Frontier-to-local bridge** (harness): frontier-generated demonstrations, plus a local policy that follows the frontier model's instructions. [paper](https://arxiv.org/abs/2610.03615)
- **RoboChemGym** (sim): protocol-driven generation of long-horizon chemistry manipulation demonstrations. [paper](https://arxiv.org/abs/2610.02708)
- **ManiPhysicsBench** (benchmark): checks whether VLA manipulation preserves objects, using a deformation and fracture solver. [paper](https://arxiv.org/abs/2610.02802)
- **Detect and Suppress** (safety): an inference-time defense against adversarial patches based on sparse-autoencoder features. [paper](https://arxiv.org/abs/2610.03498)
- **DeltaWorld** (world-model): a world simulator that predicts latent increments, for physically consistent manipulation rollouts. [paper](https://arxiv.org/abs/2610.02691)
- **Spatial Memory Intelligence** (world-model): long-term spatial memory for video world models, managed by a multimodal understanding model. [paper](https://arxiv.org/abs/2610.02521)
- **Robo-ValueRL** (data): open offline-to-online RL with reliable history-conditioned value estimation (Beijing Humanoid Robot Innovation Center and Renmin University). Promoted from the watch list now that its repository and paper are verified. [paper](https://arxiv.org/abs/2607.09866)
