# Radar · 2026-10-20

## Signals

- **The "frontier model as robot" question is now asked head-on.** SenseNova's report tests GPT-6-Astra as a standalone embodied policy across 12 benchmarks spanning tabletop, humanoid, mobile and dexterous settings, under a unified protocol with in-context demonstrations and longer step budgets. It asks what this means for specialized models. HexaShell takes the minimalist position: the harness only maps a coding agent's commands to bimanual motion, and the agent improves by writing and fixing its own tool programs from failure logs, like a coding agent fixing a failing test.
- **Self-improvement reaches multi-robot coordination.** InstAgent is an agent operating system for heterogeneous teams. Agentic behavior trees encode capability assignment and inter-robot dependencies, and execution-time corrections become reusable experience. CoEvolve represents humanoid team coordination as code and revises it with a verifier when execution deviates. VLA-Fabric goes the other way, with one full VLA per arm and coordination learned during action generation.
- **Memory gets causal evaluation.** IMEP argues that success-rate ablations cannot show whether memory is actually used, and substitutes facts at the retrieval interface instead. A new survey maps VLA memory from sliding windows to self-evolving lifelong memory, continuing the memory thread from 2026-10-05.

## Added

- **HexaShell** (harness): a thin harness for coding agents driving a bimanual robot through a command line; code released. [paper](https://arxiv.org/abs/2610.23479)
- **LAW** (harness): a closed-loop VLM plus world-action model agent unified by semantic subtask progress. [paper](https://arxiv.org/abs/2610.23334)
- **VLA memory survey** (survey): memory paradigms from sliding windows to self-evolving lifelong memory. [paper](https://arxiv.org/abs/2610.23319)
- **Model-to-Policy formulation** (survey): a probabilistic formulation unifying VLAs and world-action models. [paper](https://arxiv.org/abs/2610.23053)
- **Has GPT-6-Astra Achieved Embodied Intelligence?** (benchmark): SenseNova's 12-benchmark evaluation of a frontier model as an embodied policy. [paper](https://arxiv.org/abs/2610.22471)
- **IMEP** (benchmark): interventional evaluation of whether VLA memory is actually used. [paper](https://arxiv.org/abs/2610.23372)
- **InstAgent** (multi-agent): a recursively self-improving agent OS for heterogeneous robot teams. [paper](https://arxiv.org/abs/2610.23098)
- **CoEvolve** (multi-agent): self-evolving coordination code for humanoid teams. [paper](https://arxiv.org/abs/2610.23288)
- **VLA-Fabric** (multi-agent): composable multi-arm agents with one VLA per arm and learned interaction; code released. [paper](https://arxiv.org/abs/2610.23018)
- **VLA task-redirection attacks** (safety): closed-loop optimization of visual attacks that steer VLAs to attacker tasks. [paper](https://arxiv.org/abs/2610.23566)
- **NestedVLA** (policy): post-hoc skill consolidation through hypernetwork-generated action experts (NeurIPS 2026); code released. [paper](https://arxiv.org/abs/2610.23271)
- **SimpleVLN** (brain): an architecture-preserving recipe for native multimodal LLMs as VLN agents; code released. [paper](https://arxiv.org/abs/2610.23203)
