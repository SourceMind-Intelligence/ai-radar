# Radar · 2026-10-21

## Signals

- **The harness pattern is reaching world models.** State World Models wrap a frozen video generator in a "stateful harness". An explicit world state evolves under specified rules, the video model only renders each event, and the generated clip updates the state for the next turn, so interactions obey rules even when the relevant state is off-screen. This mirrors the policy side, where frozen VLAs get explicit state and rules around them (COAP, D-World).
- **Self-improvement gets a measurement science.** PhysRSI-eval scores VLM agents on 18 manipulation tasks under a fixed interaction budget along five axes: first-attempt performance, efficiency, success, budget and improvement from failure. Systems with similar public benchmark averages differ sharply on these axes. Together with SEAR's controls and the L0–L5 framework (2026-10-15), the self-improvement claims of the past month are becoming testable.
- **Human data keeps scaling world models.** Ropedia W0 trains a loco-manipulation world foundation model on 10k hours of egocentric human data plus 3k hours of robot data, with a unified kinematic representation; code is released.
