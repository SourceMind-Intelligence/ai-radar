# Radar · 2026-09-30

## Signals

- **The cheap guard layer sits between the model and the motor, and it is often not a model.** SAGE blocks precondition-violating actions with a roughly 250-line symbolic gate that makes no model calls. ActionGround wraps a frozen VLA in a phase-aware state machine plus a rigid-body dynamics term. RCDH swaps only a VLA's output head for a typed schema that can reject an action. All three leave the planner or policy untouched and add the "exit code" around it.
- **Frontier general models are being driven directly by harnesses, with no VLA in between.** RoboICL runs GPT-6 Astra in an in-context loop with an observation–action–receipt grammar and anchored interaction memory. MimicAgent has coding agents write quadruped reference motions that seed RL. RLE-Bench now scores coding agents on robot-learning engineering itself, including the harnesses they build.
- **"Harness" keeps spreading as the name for the build–test–refine loop outside robot control.** DeformSmith calls its asset-generation loop a physics harness. SciHorizon-eLab compiles lab protocols into certified embodied tasks with step-level success specifications.

## Added

- **RoboICL** (harness): in-context robot control with a frontier VLM, using demonstration context plus bounded anchored interaction memory; code released. [paper](https://arxiv.org/abs/2609.34261)
- **MimicAgent** (harness): an agentic harness writes quadruped reference trajectories that train example-guided RL policies. [paper](https://arxiv.org/abs/2609.24145)
- **SAGE** (verification): a model-free symbolic action gate plus local suffix re-planning for LLM task planners; code and benchmark released. [paper](https://arxiv.org/abs/2609.34268)
- **ActionGround** (verification): a training-free runtime correction layer around frozen VLAs. [paper](https://arxiv.org/abs/2609.33256)
- **F4R** (verification): a failure-driven real-to-sim-to-real loop for continual VLA self-improvement. [paper](https://arxiv.org/abs/2609.35575)
- **RCDH** (safety): a rejectable, calibrated output head that lets a frozen VLA abstain under uncertainty. [paper](https://arxiv.org/abs/2609.35039)
- **RLE-Bench** (benchmark): coding agents evaluated as robot-learning engineers across four workflows. [paper](https://arxiv.org/abs/2609.34210)
- **SciHorizon-eLab** (benchmark): an agentic compiler from lab protocols to 300 certified embodied tasks; code and data released. [paper](https://arxiv.org/abs/2609.30971)
- **JRDB-AVR** (benchmark): active visual reasoning on real robot data, scoring evidence as well as answers (NeurIPS 2026). [paper](https://arxiv.org/abs/2609.35032)
- **HappyWorld-Bench** (benchmark): world-model reliability under exploration, interaction and modification, with an Elo arena. [paper](https://arxiv.org/abs/2609.24308)
- **DeformSmith** (sim): generation of deformable assets guided by a physics harness. [paper](https://arxiv.org/abs/2609.18620)
- **Light-O1** (policy): Light Origins' embodied foundation model pretrained on human action from internet video; the Light-O1-Preview text-to-whole-body-action model is open under Apache 2.0. [blog](https://www.lightorigins.com/en/blog/light-o1)
