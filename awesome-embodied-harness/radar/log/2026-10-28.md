# Radar · 2026-10-28

## Signals

- **"Harness versus trained policy" is now tested directly.**
  - RoboHarness gives a coding agent a visual-geometric control panel. With it, Qwen3.8-Flash-Next driven through Claude Code outperforms state-of-the-art VLA models on BEHAVIOR Challenge 2025 tasks (first-party, code released).
  - Shanghai AI Lab's EBench report runs GPT-6 Astra under the same observations as post-trained policies, in two modes: direct waypoint control, and a harness that can also call a VLA or world action model.
  - PhysLadder sets a ceiling: zero-shot Astra falls from 80% real-robot success on contact selection to 0% on coordinated contact reconfiguration (first-party).
- **The harness improves itself, and keeps a lineage.** VISTA explores harness revisions actively and records them in a harness graph, so it can build on what worked and avoid failed directions. RoboDoctor revises how control is split between policy and agent, and when the agent intervenes, keeping linked experience records. ReSight lets a coding agent write new memory operations that an online agent then calls as tools. This continues SERA (2026-10-23) and FastHarness (2026-10-24).
- **Code as the glue between VLAs.** RoboDuo's coding agent never emits actions. It writes a program that lets a frozen full-task VLA attempt the task, checks completion, and hands the remaining steps to an atomic-skill VLA. ThinkLocoManip makes locomotion a tool domain in a reason-act harness for legged robots.
- **Judges and safety tests can be manipulated or engineered.** A single false "making progress" log line beside robot video flips VLM-judge verdicts 10–35 points more often than a neutral line. A one-line warning that the log may be wrong removes most of the effect (CoRL safety workshop). EAST turns documented hazards into fault-injection tests in digital twins.

## Added

- **RoboHarness (control panel)** (harness): a coding agent with a visual-geometric control panel beats VLAs on BEHAVIOR; code released. Published in September but first seen today via the Hugging Face feed. Not the same system as the two earlier RoboHarness entries. [paper](https://arxiv.org/abs/2610.14018)
- **VISTA** (harness): active self-exploration for embodied harness improvement; code released. [paper](https://arxiv.org/abs/2610.35051)
- **RoboDoctor** (harness): training-free recursive self-improvement over policy and agent; preview code. [paper](https://arxiv.org/abs/2610.35604)
- **RoboDuo** (harness): attempt, check and atomic recovery through code over two VLAs. [paper](https://arxiv.org/abs/2610.34108)
- **ThinkLocoManip** (harness): an agentic whole-body control harness for legged loco-manipulation. [paper](https://arxiv.org/abs/2610.34370)
- **EBench Astra report** (benchmark): a frontier agent with direct control versus a harness with a policy. [paper](https://arxiv.org/abs/2610.35832)
- **PhysLadder** (benchmark): a hierarchical, matched sim-real contact-rich benchmark. [paper](https://arxiv.org/abs/2610.34527)
- **RobotAgentBench** (benchmark): open-world household robot autonomy; code, data and baseline weights released. [paper](https://arxiv.org/abs/2610.34649)
- **EmbodiedLab** (benchmark): robots that must act to know, through quantitative science experiments; code released. [paper](https://arxiv.org/abs/2610.35385)
- **ReSight** (memory): task-driven, self-extending memory operations for embodied agents. [paper](https://arxiv.org/abs/2610.33487)
- **Execution Logs Sway VLM Judges** (safety): log-injection attacks on VLM progress judges. [paper](https://arxiv.org/abs/2610.34151)
- **EAST** (safety): embodied AI safety testing through fault injection in digital twins. [paper](https://arxiv.org/abs/2610.34358)
