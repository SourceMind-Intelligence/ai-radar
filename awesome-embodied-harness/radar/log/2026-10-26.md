## Signals

- **Simulation decouples from a single engine.** Isaac Lab 3.0, generally available on 20 Oct, runs one task API over several physics, rendering and visualization backends. These include Newton, which is Warp-native with MuJoCo-Warp, VBD and MPM solvers. Many workflows now run without launching Isaac Sim (per the release notes). For harness builders, the same task can be evaluated across physics engines without porting it.
- **Promised code is arriving.** CarryOn (added 2026-10-17 with "coming soon") released its dual-loop harness code on 25 Oct. MimicAgent released a humanoid implementation, in which a coding agent writes motion-generator code and checks and repairs it in MuJoCo, ahead of the quadruped code from its paper.
