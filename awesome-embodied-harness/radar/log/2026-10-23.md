# Radar · 2026-10-23

## Signals

- **The harness is now the thing being optimized.** SERA wraps a VLM planner and a fixed VLA executor in an editable harness that keeps task context, and uses environment rollouts to propose and evaluate revisions to the harness itself. With AgenticRoboRL yesterday, which post-trained the planner inside the harness, the field now has both levers: train the model, or evolve the harness. TARSphere ships a full stack (simulator with embodied NPCs, a harness for a frozen MLLM, and a benchmark) with released code.
- **Code moves inside the world model.** AW-0 jointly generates code, future video and robot actions in one model: the code stream structures multi-step prediction and is kept as reusable skill programs. Code and pretrained weights are released.
- **Surveys converge on verify and self-improve.** The Show Lab survey defines embodied agents by perceive, anticipate, plan, act and verify, and finds that few of 64 benchmarks evaluate anticipation or verification. The 93-page Physical2RSI survey sets out the conditions under which physical self-improvement can compound, extending PhysRSI-eval (2026-10-21).
- **Frontier-model-as-robot keeps getting benchmarked.** LLM-LIBERO runs six frontier models at three reasoning-effort levels over 1,800 LIBERO-10 episodes, with the best at 44% (first-party). GPT-as-Tactile-Policy reports a frontier model using tactile feedback on UniVTAC.

## Added

- **SERA** (harness): a self-evolving harness around a VLM planner and a VLA executor. [paper](https://arxiv.org/abs/2610.29560)
- **TARSphere** (framework): simulator, embodied-brain harness and benchmark for long-horizon physical and social tasks; code released. [paper](https://arxiv.org/abs/2610.30043)
- **AW-0 (Agentic World Action Models)** (world-model): code, video and action generated jointly; code and weights released. [paper](https://arxiv.org/abs/2610.30136)
- **Multimodal Embodied Agents (PAPAV)** (survey): a capability-centric survey from computer-use to robot-use. [paper](https://arxiv.org/abs/2610.30108)
- **Toward Recursive Self-Improvement in Physical AI** (survey): a position survey with a companion reading list. [paper](https://arxiv.org/abs/2610.29677)
- **LLM-LIBERO** (benchmark): frontier models on LIBERO-10 through structured tool calls; code released. [paper](https://arxiv.org/abs/2610.30051)
- **HATCH** (benchmark): a sensor-scored, physically replicable robot escape room. Promoted from the queue. [paper](https://arxiv.org/abs/2610.27485)
- **PAL (Plan First, Act Later)** (memory): the VLM writes an executable subtask list ahead of time for a VLA. [paper](https://arxiv.org/abs/2610.29329)
- **Post-hoc VLA epistemic uncertainty** (verification): single-policy uncertainty heads that need no retraining; code released. [paper](https://arxiv.org/abs/2610.29730)
- **PACT-VLA** (verification): chooses among candidate action chunks using a later observation taken just before commit. Promoted from the queue. [paper](https://arxiv.org/abs/2610.28019)
- **GPT-as-Tactile-Policy** (brain): GPT-6 Astra driven by tactile references for contact-rich tasks. Promoted from the queue. [paper](https://arxiv.org/abs/2610.28457)
- **ACE-Brain-0.6** (brain): scaled spatial-grounding supervision for the ACE-Brain line. Promoted from the queue. [paper](https://arxiv.org/abs/2610.27040)
