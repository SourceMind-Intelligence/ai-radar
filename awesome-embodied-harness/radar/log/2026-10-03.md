# Radar · 2026-10-03

## Signals

- **Simulation is becoming the harness's practice room.** RPG builds practice tasks from an offline dataset, diagnoses failures with privileged simulator state, and revises skills and the system prompt. Recova develops task and recovery behaviours in a reconstructed digital twin before verifying them on real robots. EmbodiRSI runs recursive self-improvement inside deployment-specific simulations. LiteReality-Agent supplies the twins, rebuilding real rooms as executable code inside an observe–edit–verify harness.
- **Everything learned is gated before it is kept.** RPG keeps a change only if it passes cross-task evaluation, and InterEvolve verifies every candidate reward program across parallel simulations. This continues yesterday's pattern (DynaHarness, Scale and Selection): self-improvement in harnesses now arrives together with admission tests.
- **Token budgets are now a harness design target.** PyRUA-Lean lets the agent write Python cells with local checks and retries and request only the observations it needs. Against a tool-calling baseline on the same planner, it raises success while using 65% fewer input tokens. The Embodied Agent Arena confirms that frontier VLMs are good at estimation and contact localization but still weak at completing coordinated actions.
