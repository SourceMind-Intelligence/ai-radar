# Radar · 2026-10-07

## Signals

- **Context engineering has reached robot agents.**
  - RobotUse lets the agent pick targets and poses visually, offloads geometry and control to a backend, keeps per-subgoal detail inside subagents, and updates a persistent playbook from execution.
  - RV-ICL turns a demonstration video into a hierarchy the agent browses through read-only tools: coarse keyframes to plan, contact-level clips to execute.
  - PreAct-Nav anchors local navigation decisions to persistent medium-horizon subgoals and checks predicted actions before execution.

  All three are explicitly about how much and which context the model sees, which is the coding-agent harness agenda applied to robots.
- **VLA verification is splitting into "test, then monitor."**
  - OGAM runs out-of-benchmark tests (no evaluated VLA completed any of the 24 feasible new instructions) and turns the attention divergence it finds into a runtime monitor.
  - DiVeR concentrates verifier learning on the few decision-critical states.
  - Feasible-Future Decoding argues that a locally safe action is not enough when no safe completion remains.
  - Encoded but Not in Control shows that VLAs often ignore which object the instruction names.
- **Dual-system timing is becoming adaptive.** TUD (NeurIPS 2026) calls the slow generalist only when re-predicted future actions start to disagree.

## Added

- **RobotUse** (harness): an agent harness allocating computation, context and decisions, with subagents and a continual playbook; code released. [paper](https://arxiv.org/abs/2610.04929)
- **RV-ICL** (harness): recursive, tool-navigable video in-context learning for agents that orchestrate VLAs. [paper](https://arxiv.org/abs/2610.06843)
- **PreAct-Nav** (harness): anticipatory agentic reasoning before action for urban navigation. [paper](https://arxiv.org/abs/2610.04916)
- **ARISE** (harness): an agentic social-interaction framework on the Sophia humanoid, with memory and coordinated gestures and expressions. [paper](https://arxiv.org/abs/2610.05964)
- **EvoMem-VLA** (memory): state-change "delta" memory for long-horizon VLAs. [paper](https://arxiv.org/abs/2610.05418)
- **OGAM** (verification): systematic out-of-benchmark VLA testing linked to object-grounded attention runtime monitoring. [paper](https://arxiv.org/abs/2610.05878)
- **DiVeR** (verification): decision-critical verifier learning for VLA test-time scaling. [paper](https://arxiv.org/abs/2610.04933)
- **Feasible-Future Decoding** (safety): decoding that keeps a safe completion reachable under a frozen VLA. [paper](https://arxiv.org/abs/2610.05166)
- **TUD** (policy): uncertainty-triggered generalist calls in dual-system VLAs (NeurIPS 2026). [paper](https://arxiv.org/abs/2610.05025)
- **RMMBench** (benchmark): 70 navigation-manipulation scenarios for VLM-driven robots (CoRL 2026). [paper](https://arxiv.org/abs/2610.05414)
- **Grounding gap (Encoded but Not in Control)** (benchmark): scene-preserving instruction interventions on VLAs and world-action models. [paper](https://arxiv.org/abs/2610.06235)
