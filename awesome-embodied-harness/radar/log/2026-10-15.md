# Radar · 2026-10-15

## Signals

- **The self-improvement wave is getting experimental controls.** SEAR asks the two questions most recent self-evolving harnesses skipped: is the agent learning, or just trying more often? And does what it learned transfer to new tasks, a new simulator and a real robot? It tests code-as-policy, agent-as-policy and auto-research modes under controls that separate the two. "Who Improves the Robot?" proposes an L0–L5 scale for physical recursive self-improvement and reserves the top level for independently verified recursive gains. EmbodiedEvo and D-World add two more self-improving loops: a SWE-style coding agent, and an explicit digital twin whose parameter revisions are accepted only if replay matches what the robot measured.
- **Frontier models as direct policies keep rising.** With the whole episode in context, a frozen GPT-6 Astra reports 92.1% on RoboMME's memory-dependent tasks, above the previously reported human score and the best leaderboard entry (first-party). ChunkAct goes after the cost side: once memory prescribes the routine for a chosen sub-goal, it skips re-reasoning for each primitive.
- **Evaluation keeps targeting the loop rather than the step.** SCOPER injects execution failures into full System 2 cycles, LADDER scales tasks from 1 to 10 subgoals in one scene, and EmbodiedSkillBench measures what packaged skills actually buy an agent in success, tokens and time.

## Added

- **Frontier VLM as memory policy** (harness): a frozen GPT-6 Astra as a direct end-effector policy on RoboMME; code released. [paper](https://arxiv.org/abs/2610.17350)
- **SEAR** (harness): a self-evolving agentic robotics framework and benchmark with learning-versus-retrying controls. [paper](https://arxiv.org/abs/2610.18792)
- **EmbodiedEvo** (harness): SWE-style self-improving coding agents for physical tasks. [paper](https://arxiv.org/abs/2610.18867)
- **ChunkAct** (harness): action chunking for LLM-agent robot control. [paper](https://arxiv.org/abs/2610.18874)
- **D-World** (harness): an explicit, code-based digital twin with replay-gated parameter revision. [paper](https://arxiv.org/abs/2610.17114)
- **Physical RSI (L0–L5)** (survey): a framework for recursive self-improvement in physical robots. [paper](https://arxiv.org/abs/2610.18842)
- **ForkCast** (verification): counterfactual-future recovery (commit, re-observe or replan) around frozen VLAs. [paper](https://arxiv.org/abs/2610.18650)
- **SCOPER** (benchmark): 870-task embodied System 2 benchmark with controlled execution failures. [paper](https://arxiv.org/abs/2610.17657)
- **EmbodiedSkillBench** (benchmark): 250 packaged embodied skills and a closed-loop agent benchmark; code released. [paper](https://arxiv.org/abs/2610.16238)
- **LADDER** (benchmark): long-horizon manipulation from 1 to 10 subgoals across three suites. [paper](https://arxiv.org/abs/2610.18053)
- **Code2Worlds-2** (sim): LLM-coded 4D worlds made physics-engine executable; code released. [paper](https://arxiv.org/abs/2610.17651)
- **GreenWAM** (world-model): Sber Robotics Center's world foundation model spanning 20 robot families with a shared anatomical action space; code and weights released. [paper](https://arxiv.org/abs/2610.18774)
