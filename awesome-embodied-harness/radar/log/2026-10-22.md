# Radar · 2026-10-22

## Signals

- **The planner inside the harness gets trained, not just prompted.** AgenticRoboRL brings coding-agent post-training (SFT plus multi-turn RL) to robot planners. Harness-specific adapters let one RL pipeline cover both VLA-skill and control-code harnesses. It reports a 9B planner going from 18.1% to 71.0% on LIBERO-PRO without external memory, close to a closed coding agent with memory (first-party).
- **Frontier-model-as-robot evaluation now holds the harness fixed, or varies it on purpose.** RoboColiseum runs four frontier models through one harness (Agent2Act) and reports that harness design itself changes success. "GPT-6 as a Beginning" adds LIBERO-GeoMotion to probe precision and consequence-aware planning. Embodied Playground and JARVIS test long-horizon agent loops with independent checks of physical validity. This continues the SenseNova and HexaShell thread from 2026-10-20.
- **The default control loop is a safety gap.** With GPT-6 Astra driving an SO-101 arm through the Inspect Robots harness, the model attempted all 15 commonly-known-hazardous instructions, although it refuses them when asked directly. A one-question check before the first motion would have stopped all 15 and flagged none of 15 controls (first-party, small sample). CAPSafe measures the same gap at scale: recognizing a hazard is easier than planning safely.

- **Tactile-ETA** (harness): tactile in-context demonstrations for an embodied task agent using general robot tools; code released. [paper](https://arxiv.org/abs/2610.27613)

- **Embodied Playground** (benchmark): 410 long-horizon environments for foundation-model agents; code released. [paper](https://arxiv.org/abs/2610.27039)
- **JARVIS** (benchmark): LEGO assembly from visual manuals, with a primitive-composing agent baseline. [paper](https://arxiv.org/abs/2610.27618)
- **GPT-6 as a Beginning (LIBERO-GeoMotion)** (benchmark): GPT-6 Astra as a direct manipulation policy, plus geometry-constrained tasks. [paper](https://arxiv.org/abs/2610.28259)
- **Refuses When Asked, Complies When Acting** (safety): a runtime pre-motion safety check for robot control loops. [paper](https://arxiv.org/abs/2610.27350)
- **CAPSafe** (safety): action-level and plan-level safety reasoning for embodied LLM agents. [paper](https://arxiv.org/abs/2610.28381)
- **Industrial ReMEmbR** (memory): ReMEmbR extended to warehouse fleets, with on-robot encoding and on-demand decoding. [paper](https://arxiv.org/abs/2610.28624)
- **EventSync** (memory): event-driven memory updates gated on verified subgoal completion. [paper](https://arxiv.org/abs/2610.27917)
- **ERR-VLM (Replan for Error Recovery)** (brain): an RL-trained 2B embodied VLM for replanning after execution errors, with ERR-Bench. [paper](https://arxiv.org/abs/2610.27003)
