# Radar · 2026-10-01

## Signals

- **Experience is stored outside the weights.** RoboHarn-Evo accumulates task and action knowledge from interaction and revises it across episodes. RoboSkill evolves a skill library of guidance and reusable code. ENCORE has a coding agent turn a few demonstrations into a frozen policy program. In all three the base model stays fixed and the harness carries the learning.
- **The minimum viable harness keeps shrinking.** MotorMind drops the action expert, coding agent and grounding model entirely: a general VLM issues parameterized mid-level motions to deterministic controllers, with asynchronous monitoring. SimpleARM adds memory to a frozen policy as compact typed state that is retrieved only when a subgoal needs history.
- **Evaluation itself is under audit.** The VLA acceleration audit found 22 bugs across seven benchmarks that can reverse method rankings. LIBERO-MAX shows 11–26-point drops when the world changes mid-task. ProgressCompass shows progress reward models fail without the right context. Together they suggest that many reported "exit codes" are less reliable than assumed.

## Added

- **MotorMind** (harness): a general VLM drives a robot through mid-level actions, deterministic control and asynchronous monitoring (UIUC). [paper](https://arxiv.org/abs/2609.38078)
- **RoboHarn-Evo** (harness): a dual-loop harness that evolves hierarchical physical knowledge from interaction. [paper](https://arxiv.org/abs/2609.37583)
- **RoboSkill** (harness): an Explore–Execute–Evolve skill acquisition and reuse loop with tactile feedback. [paper](https://arxiv.org/abs/2609.37810)
- **ENCORE** (harness): a coding agent writes and freezes manipulation programs from a few demonstrations. [paper](https://arxiv.org/abs/2609.37359)
- **SimpleARM** (memory): a training-free typed-state memory layer for frozen generalist policies. [paper](https://arxiv.org/abs/2609.36595)
- **ProgressCompass** (verification): context-dependent progress estimation, with ContextProgress-Bench and an agentic context loop around a frozen progress reward model. [paper](https://arxiv.org/abs/2609.36684)
- **Rho** (policy): Microsoft's open-weight bimanual VLA family with embodiment midtraining and online latent-noise adaptation. [paper](https://arxiv.org/abs/2609.38164)
- **LIBERO-MAX** (benchmark): 8,000 paired mid-task-change cases across 14 policies; code and data released. [paper](https://arxiv.org/abs/2609.36518)
- **VLA acceleration benchmark audit** (benchmark): 22 bugs and 4 design limitations across seven simulation benchmarks. [paper](https://arxiv.org/abs/2609.37771)
- **Video2Skill** (benchmark): streaming skill discovery into a persistent library; data on Hugging Face. [paper](https://arxiv.org/abs/2609.36691)
- **EMPIRIC** (world-model): a residual world model learned as code on top of a physics engine, through experiments. Promoted from the queue. [paper](https://arxiv.org/abs/2609.35047)
- **Predictive Semantic Safety** (safety): VLM event prediction, made conservative with conformal prediction, feeds a backup safety filter. Promoted from the queue. [paper](https://arxiv.org/abs/2609.34356)
