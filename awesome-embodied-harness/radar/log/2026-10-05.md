## Signals

- **History-dependent manipulation is now a crowded sub-area.** HIDE/SEEK adds a 15-task partial-observability benchmark. Divide-and-Remember learns which history to keep. BeyondSCe grasps objects referred to by their role in an earlier human interaction. These follow T2Mem, SimpleARM, RoboIRGBench and EvolvingNav from the past week, and most evaluate on RoboMME or a close variant. Memory is becoming its own evaluated layer of the harness.
- **Skill interfaces carry more than names.** APPL exposes each skill's structural prior (what the behaviour depends on) to the composing agent as part of its interface, so the planner knows where a skill applies.

## Added

- **APPL** (interface): skill structural priors serve both as a training bias and as the interface the composing agent reads. [paper](https://arxiv.org/abs/2609.35690)
- **BeyondSCe** (memory): zero-shot event-referential grasping with active view selection. Code is "coming soon". [paper](https://arxiv.org/abs/2609.39375)
- **Divide-and-Remember** (memory): a recursive action-relevant memory selector for VLAs. Promoted from the queue. [paper](https://arxiv.org/abs/2610.00982)
- **HIDE / SEEK** (benchmark): a partial-observability memory benchmark and a combined memory framework. [paper](https://arxiv.org/abs/2609.38886)
- **Ego2Act** (benchmark): goal-directed multi-step manipulation in egocentric video generation, as a world-simulator test. [paper](https://arxiv.org/abs/2610.01092)
- **THAW-VLA** (policy): distils frozen world-model features into a VLA with no deployment cost. Promoted from the queue. [paper](https://arxiv.org/abs/2609.24682)
